# 1. Overview

The **Releases** directory maintains the official release history for the **Intelligent Academy–Factory Ecosystem (IAFE)**.

Each release represents a stable milestone in the evolution of the ecosystem and may include:

- New architectures
- Frameworks
- Engineering assets
- Documentation
- Reference implementations
- Standards alignment
- Workspace updates
- Platform capabilities
- Release notes
- Validation reports

The objective is to provide a consistent, traceable, and reproducible engineering history.

---

# 2. Release Philosophy

The IAFE ecosystem follows an incremental engineering approach.

Every release should:

- Deliver measurable value.
- Be reproducible.
- Be versioned.
- Be documented.
- Be validated.
- Be traceable.
- Support future evolution.

Releases are intended to represent stable engineering baselines rather than snapshots of ongoing work.

# 5. Versioning Strategy

IAFE follows Semantic Versioning where appropriate.

```
Major.Minor.Patch
```

Examples:

```
v0.1.0

v0.5.2

v1.0.0

v2.1.4
```

General interpretation:

| Version | Meaning |
|----------|---------|
| Major | Significant architectural or platform changes |
| Minor | New functionality, frameworks or capabilities |
| Patch | Documentation, fixes, maintenance and corrections |

Pre-release versions may include identifiers such as:

```
-alpha

-beta

-rc

-prerelease
```
