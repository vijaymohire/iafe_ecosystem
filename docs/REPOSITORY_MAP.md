# Repository Map

> **Integrated Academy–Factory Ecosystem (IAFE)**

**Enterprise Repository Architecture and Navigation Guide**

---

# Purpose

The Repository Map provides a high-level view of the repositories, frameworks, platforms and capability domains that collectively form the Integrated Academy–Factory Ecosystem (IAFE).

Rather than consolidating all functionality into a single repository, IAFE adopts a federated repository architecture where each repository owns a well-defined capability while collaborating through shared interfaces, standards and integration contracts.

---


Each repository remains independently managed while contributing to the overall enterprise architecture.
